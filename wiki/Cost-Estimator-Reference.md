# Texas Septic Cost Estimator Reference

> **Quick answer:** A new conventional septic install in rural North Texas runs **$5,000–$12,000** in 2026. Repairs run **$2,500–$10,000**. Inspections run **$250–$500**. These are planning estimates, not quotes.

## Project types

The script supports:

- `new_install` — $5,000–$12,000 baseline
- `tank_replacement` — $2,500–$5,000
- `drainfield_repair` — $3,000–$8,000
- `drainfield_replacement` — $4,000–$10,000
- `inspection` — $250–$500
- `perc_test` — $250–$500
- `permit_fee` — $200–$400
- `land_clearing_per_acre` — $1,500–$3,500

## Modifiers

- `rock` — 1.20–1.40× (limestone, caliche)
- `slope` — 1.15–1.30×
- `poor_access` — 1.10–1.25×

Field experience from Out West Septic jobs in Palo Pinto, Hood, Erath, Stephens, Young, Jack, and Eastland counties (2024–2026).
